# M5Dial Creative Demo - M5Siv3D活用例

M5Dialの円形ディスプレイとエンコーダーを最大限に活用した、M5Siv3Dライブラリの魅力を体感できる統合デモアプリケーションです。

## 🎨 デモ機能一覧

### 1. HSVカラーピッカー（Color Picker）
- **エンコーダー**: 色相（Hue）の調整（0-360度）
- **タッチ**: 彩度（Saturation）と明度（Value）の調整
- **特徴**: 
  - 美しいHSVカラーホイール表示
  - リアルタイムカラープレビュー
  - 数値表示付きの直感的操作

### 2. アナログ時計（Analog Clock）
- **エンコーダー**: 時計の速度調整（時間の進み方を変更）
- **特徴**:
  - 12時間表示の美しいアナログ時計
  - 時針・分針・秒針のリアルタイム表示
  - デジタル時刻表示との併用
  - 完全にカスタマイズされた円形UI

### 3. スピードメーター（Speed Meter）
- **エンコーダー**: 速度調整（0-200km/h）
- **特徴**:
  - 自動車風のスピードメーターデザイン
  - スムーズな針の動き（慣性シミュレーション）
  - 速度制限警告表示（120km/h超過時）
  - 大きなデジタル速度表示

### 4. RFID読み取り（RFID Reader）
- **機能**: NFCカードの検出とUID読み取り
- **特徴**:
  - 美しいパルスアニメーション
  - カード検出状態の視覚的フィードバック
  - レインボーアクセスインジケーター
  - プレースホルダー実装（拡張可能）

### 5. お絵描きモード（Drawing Mode）
- **エンコーダー**: ブラシサイズ調整（1-20px）
- **タッチ**: 自由描画
- **特徴**:
  - 6色カラーパレット
  - リアルタイムブラシプレビュー
  - ワンタッチクリア機能
  - 多点描画対応

## 🎮 操作方法

### 基本操作
- **エンコーダー回転**: 各モードの主要パラメーター調整
- **タッチ**: モード固有の操作（選択、描画など）
- **ボタンA**: モード切り替え（5つのモードを循環）

### モード別詳細操作

#### カラーピッカー
```
エンコーダー → 色相調整
タッチしながらエンコーダー → 彩度・明度調整
```

#### アナログ時計
```
エンコーダー → 時間の進み速度調整
```

#### スピードメーター
```
エンコーダー → 目標速度設定（スムーズ変化）
```

#### RFID読み取り
```
NFCカードを近づける → 自動検出・表示
```

#### お絵描きモード
```
エンコーダー → ブラシサイズ調整
タッチ → 自由描画
カラーパレットタッチ → 色変更
Clearボタンタッチ → 全消去
```

## 🌟 M5Siv3Dライブラリの活用ポイント

### 1. 直感的な図形描画API
```cpp
// 円の描画
Circle(centerX, centerY, radius).draw(color);
Circle(centerX, centerY, radius).drawFrame(color);

// 線の描画
Line(x1, y1, x2, y2).draw(color);

// 矩形の描画
Rect(x, y, width, height).draw(color);
```

### 2. 柔軟なフォント描画
```cpp
Font font;
font.setSize(2)
    .setHorizontalAlign(Font::HorizontalAlign::Center)
    .setVerticalAlign(Font::VerticalAlign::Center);

font("Hello World", Font::Pos(x, y), color);
```

### 3. HSVカラー操作
```cpp
// HSVからRGBへの変換
Color color = Color::FromHSV(hue, saturation, brightness);

// カラー補間
Color interpolated = color1.lerp(color2, t);
```

### 4. 数学ユーティリティ
```cpp
// 角度変換
float rad = Math::ToRadians(degrees);

// 値の制限
float clamped = Math::clamp(value, min, max);

// 線形補間
float lerped = Math::lerp(a, b, t);
```

### 5. タッチ入力処理
```cpp
// タッチ状態の取得
if (Input::Touch.pressed()) {
    Math::Vec2i pos = Input::Touch.pos();
}

// タッチ判定
if (circle.touched()) {
    // タッチされた時の処理
}
```
